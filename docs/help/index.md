# Help and troubleshooting

Start with the visible symptom and the exact message. Keep the drawing and
preparation available so that a change can be reproduced.

| Situation | Start here |
| --- | --- |
| Import, units, selection, parameters or profile behaviour is unexpected | [Frequently asked questions](../user-guide/troubleshooting.md) |
| A toolpath is missing, a planning warning appears or export is rejected | [Toolpath and export diagnostics](../user-guide/toolpath-diagnostics.md) |
| You need usage advice or want to report a reproducible problem | [Support and issue reporting](../project/support.md) |

For tool-table mismatches specifically, see
[Resolve project-tool differences](../user-guide/tools/project-tools.md).
For output-dialect problems, check the actual selected
[postprocessor](../reference/index.md), rather than an unrelated default profile.
