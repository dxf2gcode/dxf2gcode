# Settings

Configure the application independently of the current machining preparation.
A saved project and an application profile are different things.

| Setting | Where to continue |
| --- | --- |
| General options, display precision and configuration pages | [Application settings](../user-guide/application-settings.md) |
| Units and selected initialization values | [Factory defaults](../user-guide/application-settings.md#selected-factory-defaults) |
| Separate machine/application setups | [Configuration profiles](../user-guide/application-settings.md#configuration-profiles) |
| Effects of Apply, restart and reloading | [When settings take effect](../user-guide/application-settings.md#when-settings-take-effect) |
| Initial machining values embedded in DXF layer names | [DXF layer naming rules](../user-guide/layer-naming-rules.md) |

[Tools](../user-guide/tools/index.md) explains the tool table and project-tool
snapshots. [Postprocessors](../reference/index.md) covers output configuration,
templates and controller commands. These have separate navigation sections.
