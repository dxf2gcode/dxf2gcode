# Prepare machining

Create the required operations from the selected original contours, then set
their effective values. One contour can serve several independent operations.

1. [Create steps and assign contours](../machining-steps.md): names, move/copy,
   selection, export activation and Undo/Redo.
2. [Set parameters and own values](../machining-parameters.md): depths, feeds,
   step defaults, overrides and display precision.
3. [Mill contours, clear pockets and drill](../contours-pockets-and-drilling.md):
   choose the operation kind and its supported combinations.
4. [Set compensation and lead moves](../compensation-and-leads.md): G40/G41/G42,
   allowances, entry, exit and overcut.
5. [Create and edit holding tabs](../tabs-and-breaking-layers.md): regions,
   assignments, automatic/manual sizes and tab heights.

Prepare tool definitions in [Tools](../tools/index.md). When the operations are
ready, continue with [Toolpaths and output](../output/index.md).
