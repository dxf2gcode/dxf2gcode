# Toolpaths and output

Selection, export activation, order and optimization serve different purposes.
Check the enabled operations before creating the controller program.

1. [Set the machining order](../shapes-layers-and-order.md): step/contour order,
   direction, start points and custom G-code boundaries.
2. [Optimize travel](../route-optimization.md): understand optimization choices
   and constraints separately from displaying route arrows.
3. [Check the preview and export](../preview-and-export.md): inspect planned
   movements, choose the output profile and review the generated file.

For controller-specific output, use [Postprocessors](../../reference/index.md).
For missing paths, warnings or rejected output, use
[Help and troubleshooting](../../help/index.md).
