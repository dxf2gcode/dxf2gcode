# Special applications

Choose the workflow that matches your machine or integration. These chapters
extend the normal [drawing-to-output workflow](../index.md).

- [Choose a machine mode](../machine-modes.md): milling, lathe and drag-knife
  conventions and unsupported combinations.
- [Cut with a drag knife](../drag-knife-cutting.md): alignment, depth passes,
  swivel/contact depth and migration.
- [Work with LinuxCNC / AXIS](../linuxcnc-axis.md): interactive filter export
  and the documented integration limits.
- [Use the command line](../command-line-usage.md): explicit configuration,
  postprocessor choice, optimization and output handling.

Machine mode and the output postprocessor are separate choices. See
[Postprocessors](../../reference/index.md) before adapting controller output.
