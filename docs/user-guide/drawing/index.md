# Drawing and project

The DXF supplies original geometry; the D2G project preserves machining preparation.
Check drawing units and contour structure before setting cutting parameters.

- [Select geometry, entities and layers](../geometry.md): select source contours
  without changing their drawing-layer membership.
- [Import drawings and manage projects](../import-and-projects.md): supported
  formats, units, tolerances, saving/reopening and changed drawings.

Next, choose [Tools](../tools/index.md) and [prepare machining](../preparation/index.md).
For missing geometry or unexpected dimensions, use [Help](../../help/index.md).
