# Tools

Each machining step uses one complete tool definition. Prepare the tool table
before importing a new drawing; saved projects retain their own tool snapshots.

| Task | Guide |
| --- | --- |
| Add or correct tool numbers, diameters and profile values | [Maintain the tool table](tool-table.md) |
| Choose a tool for steps or selected contour assignments | [Assign and change tools](assignments.md) |
| Understand saved tools, missing numbers and export blocks | [Resolve project-tool differences](project-tools.md) |

These pages explain tool choice in the machining project. The actual controller
commands for a physical tool change belong to
[Postprocessors → Tool changes and macros](../../reference/tool-changes.md).
