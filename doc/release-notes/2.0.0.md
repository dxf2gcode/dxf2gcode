### Why 2.0.0?

Version 2.0.0 marks a new development line built on a substantially reworked
codebase: geometry, toolpath planning, application workflows, file/configuration
adapters and the Qt interface now have separate responsibilities. A shared
toolpath plan drives preview and G-code export. The expanded machining options
and changed configuration semantics also make this more than a maintenance
update; for example, drag-knife depth increments and swivel contact depth are
now distinct settings, with migration of supported older files.

The move to GitHub brings source development, issue tracking, automated tests,
verified downloads and the growing documentation together. This accompanies
the technical milestone; a hosting move alone does not require a major version.
Documentation migration and platform/machine acceptance remain ongoing.

### Highlights of the 2.0.0 development line

This summary covers development since the
[SourceForge merge of 11 October 2026](https://github.com/dxf2gcode/dxf2gcode/commit/f5520a85d021feaf615a383f3383e238a22c0645),
rather than only the changes since the previous Develop package.

- **Geometry and compensation:** fixes for disappearing offsets, intersecting
  or split offset loops, degenerate spline ends and reversed imported curves.
- **Milling:** configurable lead-in, lead-out and overcut; per-contour finishing
  allowance; configurable pocket edge clearance and improved pocket handling.
- **Shared planning:** preview and G-code export use a common toolpath plan,
  including depth passes, lead moves and machining-mode conflict checks.
- **Drag knife:** multiple depth passes, ramps, lead moves, overcut, blade
  orientation options and separate swivel contact depth, including migration.
- **Tools and export:** per-contour tool assignment, export following the
  visible tree order, consistent GUI/CLI optimization and configurable
  tool-change macros with a documented manual LinuxCNC example.
- **Drawing controls:** improved multi-selection and mixed-value display,
  drag-and-drop, tree shortcuts, a scale bar, a tool entry circle and workpiece
  zero placement with contour-point snapping and unit-aware coordinates.
- **Configuration and languages:** multiple profiles, clearer parameter names,
  shorter labels, detailed tooltips and updated German, French and Russian
  translations; machine-mode changes refresh the drawing.
- **Project loading and reliability:** a restricted AST parser replaces
  execution of project-file code; expanded regression tests exercise geometry,
  projects, GUI workflows and exports across Python versions and PyQt5/PyQt6.
- **Distribution and documentation:** automated, verified Windows x64 ZIP/MSI,
  Python wheel and source downloads with provenance and checksums; GitHub-hosted
  development documentation and refreshed application branding.

### Compatibility

Supported older project and configuration formats have migration paths.
The former internal Python package paths (`core`, `gui`, `postpro`, etc.) have
been removed; custom integrations using those paths need adaptation. This does
not mean all older drawings or projects are incompatible. PyQt5 and PyQt6 are
supported; PySide6 support remains deferred.
