Compared with **2.0.0.dev12**, this release introduces the machining-project workflow:

- **Separate geometry and machining:** Geometry retains the original Entities/Layers;
  Machining provides named steps, one tool/kind per step, independent assignments,
  order and export activation. One contour can serve several operations.
- **Move/copy and edit selections:** reuse compatible steps, change selected
  contours' tools, edit mixed values and undo/redo machining actions.
- **Holding-tab regions:** import BREAKS geometry or draw/edit regions directly
  in 2D, with linked tree references, editable edge sizes and automatic sizing
  from tool diameter plus configured remaining tab length. Software and machine
  compensation share the original-contour reference.
- **Tool resolution and IGNORE:** resolve used project-tool deviations before
  exporting. IGNORE contours initially have no machining assignment and can
  later be assigned normally; the import-exclusion option remains separate.
- **Projects and interface:** save D2G 2.1 while reading 2.0 and legacy 1.1–1.5;
  compact grouped parameters and configurable display precision retain the full
  entered/calculated accuracy. Updated guides, current screenshots and an MSI
  installation route accompany the workflow.
- **Compatibility fix:** configuration/startup error dialogs use the compatible
  critical-icon enum under PyQt5/PyQt6.

Windows packages remain unsigned. Package checks do not establish physical
machine acceptance; macOS and final documentation visual review remain separate.
