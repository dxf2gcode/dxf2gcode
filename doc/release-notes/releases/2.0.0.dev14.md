Compared with **2.0.0.dev13**:

- **Ribbon:** Open, reload, transform, edit and export from the grouped command
  band. The view controls include tool bodies, the workpiece axes and scale bar,
  and a single switch that shows and updates the export connections live.
- **Integrated 2D and 3D:** VisPy uses the same toolpath data for its spatial
  and top views, with an animated transition to top view. The classic 2D
  canvas remains available in settings and is used when VisPy or OpenGL cannot
  start. The Windows ZIP and MSI include VisPy.
- **Canvas editing:** The spatial view supports contour selection and the
  shared canvas context menu. Click-position commands and drawing holding-tab
  regions are available in top view.
- **Holding tabs:** Select multiple regions with Ctrl and edit them together
  in the left panel. The entered tab-top Z is the absolute height. Each
  cutting pass below that height lifts over the tab, so there is no separate
  pass setting. Review migrated tab heights before exporting an existing
  project because the revised rule can affect its toolpaths.
- **DXF startup:** Choose automatic operations with cutter compensation,
  automatic operations without compensation, or geometry only. Unassigned
  contours can be added to steps later. Saved projects restore their own
  operations. Direct command-line export retains its existing import behavior.
- **Documentation:** The user guide follows the machining workflow and
  separates application settings, postprocessors and troubleshooting.

Windows packages remain unsigned. Package checks do not establish physical
machine acceptance.
